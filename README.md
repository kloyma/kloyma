<p align="right"> 𝗍𝗉𝗅: 𝗌𝗈/𝗌𝗉𝟩𝗌𝗉𝟫𝗌𝗈𝟤 ; 𝖤𝖭𝖳𝖯 [𝖭𝖾-𝖳𝗂-𝖥𝖾-𝖲𝗂] ; 𝖨𝖫𝖤 ; 𝖵⁴𝖫⁴𝖤²𝖥² ; 𝖼𝗁𝖺𝗈𝗍𝗂𝖼 𝗀𝗈𝗈𝖽 ; 𝗌𝗈𝖼𝗂𝖺𝗅 𝗂𝗇𝗍𝗋𝗈𝗏𝖾𝗋𝗍 ; 𝗌𝖺𝗇𝗀-𝗉𝗁𝗅𝖾𝗀. 𝗆𝖺𝗂𝗇 𝖿𝖽𝗌: 𝖻𝗌𝖽, 𝗆𝖺𝗋𝗏𝖾𝗅 (𝖼𝗂𝗇𝖾𝗆𝖺𝗍𝗂𝖼 𝗎𝗇𝗂𝗏𝖾𝗋𝗌𝖾), 𝗁𝖾𝗅𝗅𝗈 𝖼𝗁𝖺𝗋𝗅𝗈𝗍𝗍𝖾, 𝗆𝗍𝗉. 𝖡𝖣: 𝟢𝟪.𝟣𝟣.𝟢𝟪. 𝗂 𝗅𝗈𝗏𝖾 𝖺𝗅𝗅 𝗄𝗂𝗇𝖽𝗌 𝗈𝖿 𝗆𝗎𝗌𝗂𝖼, 𝗂’𝗆 𝖺 𝗆𝖾𝗅𝗈𝗆𝖺𝗇𝗂𝖺𝖼. 𝖽𝗇𝗂 𝗐 𝗆𝖾 𝗂𝖿 𝗎'𝗋𝖾 𝗎𝗇𝖽𝖾𝗋 𝟣𝟦, -𝗉𝗁𝗂𝗅𝖾, 𝗉𝗌𝗒𝖼𝗁𝗈𝗉𝗁𝗈𝖻𝖾 𝗈𝗋 𝗅𝗂𝗍𝗁𝗋𝗈𝗆𝖺𝗇𝗍𝗂𝖼. </p>
<br>
<p align="right"> 𝗈𝖿𝗍𝖾𝗇 𝖺𝖿𝗄 𝗈𝗋 𝗈𝖿𝖿𝗍𝖺𝖻 𝗌𝗈 𝗐𝟤𝗂 𝗂𝖿 𝗎 𝗐𝖺𝗇𝗍 𝗆𝗒 𝖺𝗇𝗌𝗐𝖾𝗋. 𝖺𝗅𝗐𝖺𝗒𝗌 𝖼+𝗁, 𝖻𝗎𝗍 𝖿𝗂𝗋𝗌𝗍, 𝖺𝗌𝗄 𝗆𝖾 𝖺𝖻𝗈𝗎𝗍 𝗂𝗍. </p>
